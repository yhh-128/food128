# Discord Server 設定步驟

這份文件帶你做三件事：

1. 建立一個你自己的 Discord Server（伺服器，可以想成你自己的聊天室大樓）。
2. 在裡面建立一個給 agent 用的頻道（大樓裡的一間房間），並拿到它的 `CHANNEL_ID`（這間房間的身分證號碼）。
3. 產生邀請連結，讓同組同學加入。

做完這份之後，接著做 `docs/discord-bot-setup.md`。

## 開始前

- 你的電腦：Windows。
- 你需要一個 Discord 帳號，並且已登入。用「Discord 桌面程式」或「瀏覽器 https://discord.com/app」都可以，畫面幾乎一樣。
- 下面按鈕名稱以英文介面為主。如果你的 Discord 是中文介面，名稱可能略有不同，找意思相近的就好。
- 在 Discord 裡，**「點」代表按滑鼠左鍵，「右鍵點」代表按滑鼠右鍵**。

---

## 一、建立你自己的 Server

1. 打開 Discord，看畫面**最左邊**那一條直的圖示列。
2. 在那一條的最下面，找到一個**綠色的「＋」圓形按鈕**（滑鼠移上去會顯示 Add a Server），點它。
3. 跳出「Create a server」視窗，點 **Create My Own**（自己創建）。
4. 下一個畫面問你用途，點 **For me and my friends**（給我和我的朋友）。
5. 在 **Server Name** 欄位輸入一個名字，例如 `food128`。
6. （圖示可以不用上傳，直接跳過。）
7. 點視窗右下角的 **Create**（建立）。
8. 畫面會切到你的新 Server。最左邊的圖示列會多一個圓形圖示，就是它。

> 如果還跳出「你的第一個頻道」之類的歡迎畫面，直接關掉就好。

---

## 二、建立 agent 用的頻道

這個頻道**只給這個 agent 用**，大家之後都在這裡傳食物照片。

1. 看畫面**左邊第二欄**（Server 名字的下面），找到 **TEXT CHANNELS**（文字頻道）這一行。
2. 把滑鼠移到這一行上，右邊會出現一個小小的 **「＋」**，點它。
3. 跳出「Create Channel」視窗，**Channel Type** 選 **Text**（文字，預設就是它）。
4. 在 **Channel Name** 輸入名字，例如 `food-log`。Discord 會自動轉成小寫，空白會變成 `-`，這是正常的。
5. **Private Channel**（私人頻道）的開關**保持關閉**。（原因：如果設成私人，之後還要另外手動讓 bot 進來，先不要增加麻煩。）
6. 點右下角的 **Create Channel**。
7. 左邊的頻道清單會出現 `# food-log`，點它進去，這就是 agent 要聽的頻道。

---

## 三、拿到 CHANNEL_ID

`CHANNEL_ID` 是一長串數字。Discord 預設不讓你看到，要先打開「開發者模式」。

### 3.1 打開開發者模式（只要做一次）

1. 看畫面**左下角**，你的使用者名稱旁邊有一個**齒輪圖示（User Settings，使用者設定）**，點它。
2. 在左邊的選單往下找，點 **Advanced**（進階）。
3. 找到 **Developer Mode**（開發者模式）的開關，把它**打開**（變成綠色）。
4. 按右上角的 **✕**（或鍵盤的 `Esc`）離開設定。

### 3.2 複製頻道 ID

1. 在左邊的頻道清單，找到剛剛建立的 `# food-log`。
2. **右鍵點**它。
3. 在跳出的選單最底下，點 **Copy Channel ID**（複製頻道 ID）。
4. 現在這串數字已經在你的剪貼簿裡了。
5. 打開「記事本」，按 `Ctrl + V` 貼上看看。它應該是一串 **17～20 位的純數字**，例如 `1234567890123456789`。
6. 先把它留在記事本裡，等一下設定 `.env` 時要用。

> **如果右鍵選單裡找不到 Copy Channel ID：** 表示開發者模式沒有打開成功，回到 3.1 檢查那個開關是不是綠色的。
>
> **CHANNEL_ID 不是機密**，貼給同學看沒關係。但不要跟 `DISCORD_TOKEN` 搞混，那個才是絕對不能公開的（見 `docs/discord-bot-setup.md`）。

## 四、產生邀請連結給同學

### 4.1 先想一下誰會進來

每張照片都會用掉**你自己的 Claude 額度**（見 `docs/architecture.md` 第 13 節）。**能進這個頻道的人，就能花你的額度**，所以只邀請你信任的同組同學，不要把連結貼到公開的地方。

### 4.2 產生連結

1. 在畫面**左上角**，點你的 **Server 名字**（例如 `food128`），會往下展開一個選單。
2. 點 **Invite People**（邀請其他人）。
3. 跳出視窗後，找到視窗下方的 **Edit invite link**（編輯邀請連結）或齒輪圖示，點它。
4. 設定這三項：
   - **Expire After**（多久後失效）：選 **7 days**（7 天）。測試期夠用，過期就不能再用，比較安全。
   - **Max number of uses**（最多可使用幾次）：選你同學的人數，或 **10 uses**。
   - **Grant temporary membership**（臨時成員）：**保持關閉**。
5. 點 **Generate a New Link**（產生新連結）。
6. 視窗裡會出現一條 `https://discord.gg/xxxxxxx` 的網址，點它旁邊的 **Copy**（複製）。
7. 把這條網址傳給同學（用 LINE、Email 都可以）。

### 4.3 同學怎麼加入

1. 同學打開那條網址，點 **Accept Invite**（接受邀請）。
2. 他們會自動出現在你的 Server 成員清單，也看得到 `# food-log`。
3. 你可以在 Discord 右邊的成員清單確認他們進來了。

### 4.4 想收回邀請時

1. 左上角點 Server 名字 → **Server Settings**（伺服器設定）。
2. 左邊選單點 **Invites**（邀請）。
3. 找到那條邀請，點右邊的 **✕** 把它刪掉，連結立刻失效。
