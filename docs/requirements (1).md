# 需求說明：禮物辨識與心意指數評分助理（gift-agent）

> 這份文件取代原本的「食物照片記錄 agent」需求。換主題的原因：課程規定不能做食物主題。
> 範圍與決定來自「從食物版改成禮物版」的分析與討論。舊版需求仍保留在 git 歷史裡。

## 這是什麼

一個在我自己電腦上執行的 Discord agent（會自己收訊息、做事、回覆的小程式）。只要它開著，指定頻道裡的人就可以：

- 傳一張**自己送出去的禮物**的照片，agent 會辨識它是什麼、什麼品牌、大概值多少錢，並打一個 1～10 分的**心意指數**；
- 為每個人自動建立「**個人禮物櫃**」，記下他送過的每一件禮物；
- 用日常說話的方式查詢、統計、修改、刪除自己的禮物，或請 agent **推薦**適合送的禮物。

agent 關掉就不處理。

## 誰會用

我自己的 Discord Server 裡、那個指定頻道的任何人（用手機或電腦都可以）。**每個人只看得到、也只能改自己的禮物櫃**，不能看別人的。

## 使用的流程

### 一、登錄一件禮物

1. 有人在頻道傳一張禮物照片，可以順便打幾個字說明，例如「這是送給媽媽的生日禮物，我自己做的，預算 500」。
2. agent 對那則訊息加上 ⏳，表示收到、排隊中。
3. agent 辨識：禮物名稱、種類、品牌、估計價格，並從說明裡抓出場合、送給誰、是不是手作、預算。
4. agent 依公開的評分標準打**心意指數（1～10 分）**，並說明理由。
5. agent 把這件禮物記進該使用者的禮物櫃、存好照片，再回覆這件禮物的辨識結果與分數，並附上這位使用者目前的禮物櫃統計（共幾件、平均心意指數）。

### 二、第一次出現的人

人第一次在頻道發言時，agent 會說明這個助理怎麼用，每人只說一次：

1. 傳自己送出去的禮物照片，就會辨識並打心意指數；
2. 輸入 `/禮物櫃` 可以打開自己的禮物櫃；
3. 說出要送禮的對象，agent 就能推薦適合的禮物。

### 三、用日常說話的方式互動

在頻道 @agent，或回覆 agent 的訊息，用一般的話說就好，例如：

- 「我今年送過哪些禮物？」「我送給媽媽的有哪些？」
- 「幫我統計這個月的心意指數」「哪一類禮物我得分最高？」
- 「#3 其實是手作的」「#2 的送出日期改成去年 12 月 25 日」
- 「刪掉 #5」（刪除前會先請我按按鈕確認）
- 「幫我重新評分 #3」
- 「我同事下週生日，預算 800，她喜歡植物，幫我推薦」
- 「記住：我喜歡實用型的禮物」

另外，輸入斜線指令 `/禮物櫃` 可以直接看自己的禮物櫃（最新的在最上面，只有自己看得到，不用 @agent）。

沒有 @agent、也沒有附照片的聊天文字，agent 完全不理。

## 要記錄的內容（存成同一個 Excel 檔，所有人的紀錄分行列出）

**禮物櫃**（每件禮物一列，一個人的每一列都有他自己的使用者 ID）：

- 編號（每個人各自從 1 開始，刪掉的編號不會重複使用）
- 送出日期、登錄時間
- 上傳者、使用者 ID
- 禮物名稱、種類、品牌
- 估計價格（新台幣）、辨識信心（高／中／低）
- 場合、送給誰、是否手作、預算
- 心意指數（1～10）以及四個分項分數、評分理由
- 備註
- 狀態（有效／已刪除）
- 照片存放位置

**修改歷史**（只增加、不覆蓋）：每次新增、修改、刪除、重新評分都記一列：時間、誰、哪件禮物、做了什麼、改哪個欄位、舊值、新值、使用者當時說的話。

**偏好**：每個人自己的偏好（例如「喜歡實用型」「對花粉過敏」），推薦禮物時會用到。

**已歡迎**：記錄哪些人已經收過使用說明，每人一列，確保每個人只被歡迎一次。

照片另外存進資料夾，每個使用者一個子資料夾，檔名用「日期時間 + 禮物名稱簡稱」。

## 心意指數怎麼算

不是 AI 憑感覺給一個總分，而是公開、固定的標準：

| 分項 | 比重 | 看什麼 |
|---|---|---|
| 價值感 | 25% | 價格，以及相對於預算（有提供的話）是否用心 |
| 用心程度 | 30% | 手作、客製化、包裝、花的時間 |
| 貼近對方 | 25% | 是否符合場合與對方的喜好 |
| 獨特性 | 20% | 是否特別、不是隨手可得的選擇 |

AI 只負責給四個分項（各 1～10 分）和理由，**總分由程式用上面的比重計算**，所以同樣的分項一定得到同樣的總分。資料不足時（例如沒說送給誰），AI 要照實標示「資料不足」，不能亂編。

## 隱私的規則

- 每個人只能看到、查詢、修改、刪除**自己**的禮物櫃；統計也只算自己的。
- 「你是誰」只由 Discord 決定（使用者 ID），**絕不能**由使用者打的字或 AI 的回答決定。
- 這一版**回覆都貼在公開頻道**（已確認接受；唯一的例外是 `/禮物櫃` 指令，回覆只有本人看得到）：頻道裡的人看得到你傳的禮物照片和 agent 的回覆。隔離的是「不能透過 agent 查別人的禮物櫃」，不是「別人看不到你在頻道裡公開講的話」。
- 我（管理者）可以直接打開電腦上的 Excel，看得到所有人的資料。

## 不是禮物的時候

照片裡看不出任何可以當禮物的東西（例如自拍、風景、螢幕截圖），或太暗太糊看不清楚時：回覆告訴上傳者原因，請他重傳；**不建檔**，也不計入統計。

## 畫面上 / 回覆上要有

- 收到照片時先有 ⏳；處理完換成 ✅（失敗換成 ❌）
- 登錄完回覆：禮物名稱、種類、品牌、估計價格（含信心）、場合與送給誰（有的話）、心意指數與四個分項、理由、編號，以及目前的禮物櫃統計
- 修改後回覆「改了什麼：舊 → 新」；刪除前要按「確認／取消」按鈕

## 不需要的

- 註冊、登入
- 長時間、大規模的雲端服務（這就是一支開著才會動的本機程式）
- 記錄「收到的禮物」（只記送出去的）
- 每日目標、關機期間傳的照片補處理、影片／PDF／GIF 分析
- 對話記憶（每一句話獨立處理，不記得上一句）
- 真正聯網搜尋商品或查庫存（推薦只給類型與價格範圍，不保證有貨）

## 技術上我知道的

- 用 Python 3.12 + uv；專案名稱 `gift-agent`，Python 套件名稱 `gift_agent`
- 照片與文字都用 `claude -p` 在我這台電腦上處理
- Discord 用 Gateway（bot）模式，不需要 ngrok
- 紀錄存成一個可以持續往下加的 Excel 檔，裡面分成「禮物櫃」「修改歷史」「偏好」「已歡迎」四張工作表
- 設定放在 `.env`：`DISCORD_TOKEN`、`CHANNEL_ID`、`CLAUDE_MODEL`、`DATA_DIR`

## 做事的順序

1. 先把 agent 做好，**五段防護**全部開著，自己測到正常
2. 之後（上課時）再把防護逐段關掉做對照

五段防護：

1. 防護 1：`claude -p` 的檔案範圍隔離
2. 防護 2：使用者打的字只當資料，不當指令
3. 防護 3：禮物名稱當檔名前先清洗
4. 防護 4：寫進 Excel 的文字不能被當成公式
5. 防護 5：個人隔離（只能存取自己的禮物櫃）

## 已決定的事

| 項目 | 決定 |
|---|---|
| 回覆方式 | 公開頻道（接受隱私上的取捨）；`/禮物櫃` 斜線指令的回覆只有本人看得到 |
| 心意指數 | 依公開標準由 AI 給分項、程式算總分，不單靠照片猜 |
| 禮物方向 | 只記「送出去」的 |
| 禮物櫃與每次上傳 | 同一個東西：每次上傳就是禮物櫃的一列 |
| 防護 | 加入第五段「個人隔離」 |
| Excel | 同一個檔案，不同人的紀錄分行列出 |
| 刪除 | 標記為「已刪除」，不真正刪掉列，這樣修改歷史才查得到 |
| 命名 | 專案 `gift-agent`，套件 `gift_agent` |
